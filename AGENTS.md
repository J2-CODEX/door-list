# Aprobaciones

- Para las tareas solicitadas, edita archivos dentro de este repositorio sin pedir confirmación previa por cada edición.
- Antes de ejecutar cualquier comando que acceda a una base de datos, pide confirmación explícita al usuario, incluso si es de solo lectura.
- Antes de ejecutar cualquier comando que instale dependencias, pide confirmación explícita al usuario.
